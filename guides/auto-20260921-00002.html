식당 운영

배달 병행 식당 영업 전 주문·결제 운영 점검 가이드

매장과 배달 주문이 동시에 들어오기 전에 판매 상태, 요청 담당, 카드단말기, 미완료 업무를 순서대로 확인하는 실무 가이드입니다.

작성 기준 2026-09-20

1. 판매 상태부터 한 화면씩 맞추기

배달 병행 식당은 영업 시작 전 매장 안내와 주문 화면의 판매·품절 상태가 같은지 먼저 확인해야 합니다. 차이가 있으면 주문 접수 뒤 변경 안내가 늘어날 수 있습니다.

담당자는 실제 판매 가능한 메뉴를 기준으로 매장 안내와 주문 화면을 차례로 대조하는 방식을 제안합니다. 품절 예정 메뉴가 있다면 표시 변경 여부와 직원 공유까지 한 묶음으로 확인해 보세요.

  1. 판매 가능한 메뉴를 확인합니다.
  2. 주문 화면의 품절 표시를 맞춥니다.
  3. 변경 내용을 직원에게 알립니다.

2. 예약과 특별 요청의 담당 정하기

예약과 특별 요청은 확인만 하고 담당자를 정하지 않으면 영업 중 대응이 늦어질 수 있습니다. 영업 전에는 요청 내용, 처리 담당자, 전달 완료 여부를 함께 살펴보는 것이 좋습니다.

예를 들어 특정 요청이 접수됐다면 주문을 처음 보는 직원이 누구에게 전달해야 하는지 알 수 있도록 담당자를 적어두는 방식을 제안합니다. 교대가 있다면 전달 여부도 짧게 표시해 두세요.

  1. 예약과 요청 내용을 모읍니다.
  2. 요청별 담당자를 정합니다.
  3. 교대 직원에게 처리 상태를 전합니다.

3. 무선 카드단말기 사용 준비 확인하기

결제 단계에서 장비 위치나 용지 상태를 찾기 시작하면 매장 주문과 배달 주문 대응이 함께 밀릴 수 있습니다. 영업 전 프리비즈 LC-7351QN 무선 카드단말기의 위치, 충전 상태, 용지 보관 위치를 확인해 두는 것을 제안합니다.

해당 단말기는 장비 구매 없이 무상 지원되며 월 통신료·사용료·임대료는 0원이고, 정산은 다음 영업일에 진행됩니다. 모아밴은 상품 상담·모집과 단말기 개통을 연결하는 대리점입니다.

  1. 단말기 위치와 충전을 확인합니다.
  2. 용지 위치와 교체 준비를 봅니다.
  3. 결제 담당자에게 위치를 공유합니다.

4. 미완료 항목에 다음 행동 남기기

점검에서 끝내지 못한 항목은 단순히 표시만 하지 말고 다음 행동을 적는 방법을 제안합니다. 예를 들어 ‘품절 표시 미완료’ 옆에 ‘주문 화면 수정 후 직원 공유’처럼 행동과 확인 순서를 남깁니다.

담당자와 완료 확인 시점을 함께 적어두면 영업 중 다시 판단하는 일을 줄이는 데 도움이 될 수 있습니다. 단말기 상담이나 개통 연결이 필요한 경우에는 모아밴에 확인할 질문을 먼저 정리해 보세요.

  1. 미완료 항목을 따로 표시합니다.
  2. 다음 행동과 담당자를 적습니다.
  3. 영업 직전 완료 여부를 확인합니다.

실행 점검표

  • 판매·품절 안내와 주문 화면이 일치합니다.
  • 예약과 특별 요청의 담당자가 정해졌습니다.
  • 단말기·용지·충전 위치를 확인했습니다.
  • 미완료 항목마다 다음 행동을 적었습니다.
  • 변경 사항을 영업 담당자에게 공유했습니다.

프리비즈 LC-7351QN 상담 전에 무엇을 준비하면 되나요?
