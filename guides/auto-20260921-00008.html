출장 수리업 영업 전 현장 대응과 기록 준비 가이드

첫 방문부터 작업 종료까지 혼선을 줄이도록 출동 정보, 담당 역할, 현장 기록 양식과 돌발 상황 대응 순서를 미리 맞추는 운영 가이드입니다.

출동 정보와 작업 범위를 먼저 맞추기

영업을 시작하기 전, 접수 담당자와 출동 담당자가 방문지·요청 내용·현장 조건을 같은 기준으로 확인해야 합니다. 확인 결과는 한 장의 출동 기록에 모아 현장에서 다시 묻는 일을 줄입니다.

접수 담당자는 고객이 말한 증상을 임의로 확정하지 않고 관찰된 현상과 요청 사항을 구분해 적습니다. 출동 담당자는 기록을 읽고 필요한 확인 도구와 작업 공간 확보 여부를 점검한 뒤 준비 완료 표시를 남깁니다.

  1. 방문지와 연락 방법을 대조합니다.
  2. 증상과 요청 사항을 나눠 적습니다.
  3. 출동자가 준비 완료를 표시합니다.

휴대 물품과 기록 양식 준비하기

출동 담당자는 자주 쓰는 공구, 보호용품, 소모품과 기록 도구를 종류별로 나눠 확인합니다. 물품 이름만 보는 대신 정상 사용 가능 여부와 수량을 함께 적고, 부족하거나 손상된 물품은 별도 보관해 현장 반입을 막습니다.

현장 기록지는 방문 전 상태, 고객 요청, 확인 과정, 작업 내용, 작업 후 상태를 차례로 적을 수 있게 준비합니다. 사진 기록이 필요할 때는 촬영 목적과 대상을 먼저 정하고, 담당자가 파일 이름에 방문 구분과 촬영 순서를 표시합니다.

  1. 물품 상태와 수량을 함께 확인합니다.
  2. 이상 물품은 사용 물품과 분리합니다.
  3. 기록지와 촬영 순서를 준비합니다.

접수·출동·지원 역할을 구분하기

접수 담당자는 방문 정보 변경과 추가 요청을 기록하고 출동 담당자에게 전달합니다. 출동 담당자는 이동 전 최신 기록을 다시 읽으며, 현장에서는 확인되지 않은 원인을 단정하지 않고 관찰 내용과 수행한 작업만 남깁니다.

혼자 운영한다면 시간을 나눠 역할을 전환합니다. 출발 전에는 접수자 관점으로 누락을 확인하고, 현장 도착 후에는 작업자 관점으로 상태를 기록합니다. 추가 물품이나 동료 도움이 필요하면 지원 요청 시각, 필요한 내용, 전달받은 결과를 이어서 적습니다.

  1. 변경 사항의 전달자를 정합니다.
  2. 출발 전에 최신 기록을 읽습니다.
  3. 지원 요청과 응답을 이어 적습니다.

출발 전 모의 점검과 인계 마무리

첫 출동 전 짧은 모의 상황을 진행합니다. 접수 담당자가 가상의 요청을 전달하면 출동 담당자는 방문 정보, 준비 물품, 현장 첫 확인 순서를 말로 되짚습니다. 빠진 내용은 구두로만 고치지 말고 출동 기록에 즉시 보완합니다.

교대가 예정되어 있다면 미완료 준비, 확인이 필요한 방문, 분리 보관한 물품을 인계 기록에 남깁니다. 다음 담당자는 내용을 읽은 뒤 이해한 사항과 다시 확인할 사항을 구분해 표시하고, 출발 직전 최종 확인자를 한 명으로 정합니다.

  1. 가상 요청으로 준비 순서를 맞춥니다.
  2. 누락 사항을 기록에 보완합니다.
  3. 다음 담당자가 인계 내용을 확인합니다.

실행 점검표

  • 방문 정보와 고객 요청이 한 기록에 정리되어 있습니다.
  • 공구·보호용품·소모품의 상태와 수량을 확인했습니다.
  • 접수·출동·지원 담당자의 기록 범위를 정했습니다.
  • 변경 사항과 교대 인계를 확인할 담당자가 지정되어 있습니다.

자주 묻는 질문

고객 요청이 출발 직전에 바뀌면 어떻게 기록하나요?

접수 담당자가 기존 요청을 지우지 않고 변경 시각과 새 요청을 이어 적습니다. 출동 담당자는 준비 물품과 현장 확인 순서를 다시 검토한 후 확인 표시를 남깁니다.

한 사람이 접수와 출동을 모두 맡을 때는 어떻게 하나요?

출발 전과 현장 도착 후의 기록 칸을 나눕니다. 출발 전에는 방문 정보와 준비물을 확인하고, 도착 후에는 실제 상태와 수행 순서를 기록해 두 역할의 내용이 섞이지 않게 합니다.
