상자를 연 뒤 먼저 확인할 것

단말기 본체, 지급받은 충전기, 용지와 설치 안내문을 한곳에 놓으세요. 기기 모델과 관리 연락처를 확인하고, 충전 연결부나 용지 덮개에 눈에 띄는 손상이 없는지 살펴봅니다. 사용법이 비슷해 보여도 다른 기종의 버튼 조합을 그대로 적용하지 않습니다.

전원이 켜진다는 사실만으로 개통 완료를 판단하지 마세요. 담당자에게 매장 등록과 사용할 결제 방식의 준비가 끝났는지 확인합니다. 첫 영수증에서 볼 상호와 사업자 정보도 준비해 두면 설치 당일 잘못된 등록을 발견하기 쉽습니다.

첫 결제를 진행하는 흐름

실제 주문을 받을 때는 주문서 합계와 단말기 금액을 소리 내어 대조하세요. 예를 들어 두 사람이 식사하고 추가 메뉴를 주문했다면 최초 주문 금액이 아니라 추가 주문까지 반영한 합계를 확인합니다. 연습은 설명 화면이나 담당자 시연으로 진행하고 임의의 허위 매출을 만들지 않습니다.

  1. 영업 시작 전 충전 상태, 용지 잔량, 화면의 통신 상태를 확인합니다.
  2. 주문 금액을 확인한 다음 설치 안내와 화면 순서에 따라 결제를 시작합니다.
  3. 고객에게 카드 또는 휴대전화를 제시할 위치를 안내하고 처리 결과를 기다립니다.
  4. 승인 여부와 금액을 확인하고 영수증을 제공합니다. 결과가 불명확하면 재결제부터 하지 않습니다.

첫날 끝내기 전 남길 기록

첫 거래의 금액과 매장 표시가 맞으면 다음 손님에게 같은 순서로 안내합니다. 영수증만 안 나오는 문제와 승인이 안 되는 문제는 구분하세요. 영수증이 없더라도 이미 승인됐을 수 있으므로 거래 조회나 관리 담당자의 확인이 필요합니다.

마감 때 승인과 취소 내역을 확인하고, 잘 몰랐던 화면을 개인정보가 보이지 않도록 정리해 둡니다. 금액 확인 담당자, 취소 승인 담당자, 장애 연락처를 정하면 직원이 바뀌어도 운영 기준이 유지됩니다. 이 글은 일반적인 첫날 운영 안내이며 실제 메뉴 위치는 설치 안내서를 따릅니다.

실행 점검표

  • 개통 완료와 사용 가능한 결제 방식을 확인했습니다.
  • 주문서 합계와 승인 금액이 일치합니다.
  • 영수증의 매장 정보와 관리 연락처를 확인했습니다.
  • 결과가 불명확할 때 문의할 담당자를 정했습니다.

자주 묻는 질문

연습하려고 작은 금액을 결제해도 되나요?

임의로 거래를 만들기보다 담당자 시연을 요청하세요. 실제 거래로 작동을 확인하는 경우에도 승인·취소 내역과 처리 결과를 함께 관리해야 합니다.

첫날 모든 기능을 외워야 하나요?

기본 승인, 거래 확인, 용지 교체, 문의 방법부터 익히면 됩니다. 취소와 설정 변경은 담당자에게 한 번 더 확인하고 진행하세요.
