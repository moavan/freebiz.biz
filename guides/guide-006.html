영수증에 글자가 안 나올 때: 백지 출력 점검 순서

종이는 나오는데 글자가 보이지 않는다면 용지 방향과 종류부터 확인합니다. 승인 여부와 출력 문제를 나누어 점검하고, 새 거래를 만들지 않고 해결 여부를 확인하는 방법입니다.

백지 출력과 결제 실패는 다른 문제입니다

고객 카드가 승인된 뒤 빈 종이만 나왔다고 해서 결제가 실패했다고 판단하지 마세요. 먼저 화면과 거래 내역에서 해당 시각의 금액과 승인 상태를 확인합니다. 고객에게는 ‘결제 결과를 확인하고 영수증 출력을 점검하겠습니다’라고 안내합니다.

언제부터 백지가 나왔는지도 중요합니다. 용지 교체 직후라면 넣는 방향이나 용지 종류를 우선 확인할 이유가 있습니다. 기존 용지를 계속 쓰다가 갑자기 흐려졌다면 출력 상태 사진과 발생 시점을 남겨 상담 때 설명하세요. 원인은 점검 전까지 추측으로 구분합니다.

용지부터 순서대로 확인하세요

기기 안쪽 표시나 설치 안내를 보고 인쇄면 방향을 맞춥니다. 이미 확인된 규격의 새 롤이 있다면 그것으로 비교하되, 방향을 알아내려고 라이터나 뜨거운 기구를 사용하지 않습니다. 종이 표면에 약품을 바르거나 프린터 내부에 액체를 넣는 방법도 피합니다.

  1. 진행 중인 출력이 끝났는지 확인하고 덮개를 안내대로 엽니다.
  2. 현재 용지가 지급품 또는 확인된 규격인지 확인합니다.
  3. 표시된 방향으로 넣고 덮개를 바르게 닫습니다.
  4. 기존 거래 재출력 또는 지원되는 인쇄 확인 기능으로 결과를 살핍니다.

여전히 백지라면 점검을 멈출 기준

정상 용지와 올바른 방향을 확인했는데도 계속 백지가 나오면 프린터 점검을 요청하세요. 인쇄 농도, 내부 설정, 초기화 값을 임의로 바꾸면 상담 담당자가 최초 증상을 파악하기 어려워집니다. 무엇을 바꿨고 결과가 어땠는지 한 줄씩 기록해 전달합니다.

예를 들어 ‘새 롤 교체 뒤 전체 백지, 기존 지급 용지로 다시 확인해도 동일’이라고 알려주면 단순히 ‘영수증 안 됨’이라고 말하는 것보다 확인할 범위가 명확해집니다. 고객에게 제공할 영수증은 지원되는 공식 조회·재출력 경로를 상담받고, 임의로 카드 전표처럼 보이는 문서를 만들어 대신 제공하지 않습니다.
