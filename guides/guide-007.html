카드단말기 사용 가이드 007

카드단말기 용지가 걸렸을 때, 안전하게 확인하는 순서

용지가 안 나온다고 계속 당기거나 반복 출력하지 마세요. 거래 결과를 먼저 확인하고 덮개 주변의 보이는 걸림만 점검한 뒤, 수리가 필요한 상황을 구분하는 방법입니다.

모아밴 편집 안내 · 작성 기준 2026-09-19

이 글에서 확인할 내용
  1. 멈춘 것은 출력인지 거래인지 살핍니다
  2. 보이는 종이와 롤 상태를 확인합니다
  3. 반복되면 남길 증상과 문의 기준

멈춘 것은 출력인지 거래인지 살핍니다

종이가 비뚤게 나오거나 중간에 멈추면 먼저 출력 동작과 화면 메시지를 확인합니다. 결제 도중 발생했다면 거래 시각과 금액을 적고 승인 결과를 조회하세요. 출력이 끝나지 않았다는 사실만으로 새 결제를 시작하면 거래 확인이 더 복잡해집니다.

종이가 걸린 위치를 밖에서 확인하고 단말기를 평평한 곳에 놓습니다. 덮개를 여는 절차와 전원 처리 방법은 실제 기기 안내를 따릅니다. 강하게 잡아당기거나 인쇄 버튼을 연속으로 누르기보다 현재 상태를 유지해 원인을 확인하는 편이 낫습니다.

보이는 종이와 롤 상태를 확인합니다

덮개를 열 수 있는 정상 절차가 확인되면 롤이 비뚤게 들어갔는지, 끝부분이 접혔는지 살펴봅니다. 손으로 쉽게 꺼낼 수 있는 느슨한 조각만 정리하세요. 내부 깊숙한 곳을 핀셋·칼·드라이버로 건드리거나 프린터를 분해하는 방법은 이 점검 범위가 아닙니다.

  1. 진행 중인 거래의 결과를 확인하고 인쇄를 더 시도하지 않습니다.
  2. 설치 안내에 따라 덮개를 열고 롤과 종이 끝의 걸림을 봅니다.
  3. 정상 규격 용지를 바르게 놓고 덮개가 무리 없이 닫히는지 확인합니다.
  4. 기존 거래를 한 번 재출력해 종이가 곧게 나오고 내용이 읽히는지 확인합니다.

반복되면 남길 증상과 문의 기준

새 용지를 바르게 넣어도 같은 위치에서 멈추거나 덮개가 닫히지 않으면 사용을 멈추고 담당자에게 문의하세요. ‘교체 직후 한 번’인지 ‘출력할 때마다 반복’인지, 롤이 거의 끝났는지 새 롤인지 함께 알려주면 점검에 도움이 됩니다.

점심시간에 종이가 걸린 상황이라면 한 직원은 고객에게 결제 결과를 안내하고, 다른 직원 또는 책임자가 출력 문제를 맡도록 역할을 나눠 보세요. 종이가 정상 배출되고 기존 거래 영수증이 제대로 출력돼야 해결로 표시합니다. 이후 교대 직원에게 걸림 발생과 사용한 용지를 알려 같은 확인을 반복하지 않게 합니다.

한 번 더 확인해 보세요

실행 점검표

  • 승인 결과를 먼저 확인했습니다.
  • 종이를 세게 당기거나 반복 출력하지 않았습니다.
  • 확인 가능한 롤과 접힌 부분만 점검했습니다.
  • 정상 용지에서도 반복되면 A/S에 넘깁니다.

자주 묻는 질문

조각이 보이면 도구로 꺼내도 되나요?

내부 부품을 건드리는 도구 작업은 하지 마세요. 쉽게 제거되는 느슨한 종이 범위까지만 확인하고 접근이 어려운 조각은 담당자 점검을 받습니다.

덮개를 눌러 닫으면 해결되나요?

힘을 줘야 닫힌다면 롤 크기나 걸림 상태부터 확인하세요. 정상적인 닫힘이 되지 않으면 반복해서 누르지 말고 문의합니다.
