식당 카드 매출 마감: 승인액·취소액·입금액을 나누어 보세요

하루 영업을 마칠 때는 단말기 합계만 보고 끝내지 마세요. 주문 기록과 승인·취소 내역을 맞추고, 실제 입금은 정산 내역과 따로 확인하는 간단한 마감 순서를 정리했습니다.

먼저 마감하는 시간 범위를 정합니다

일일 집계를 볼 때 달력상 오늘 기준인지, 이전 집계 이후 기준인지 확인하세요. 자정을 넘겨 영업하는 식당이라면 영업일과 결제 날짜가 다를 수 있어 기준을 직원끼리 맞추는 것이 좋습니다. 실제 집계 메뉴와 초기화 여부는 설치 안내를 먼저 확인합니다.

포스 주문 합계, 단말기 승인 합계, 취소 합계, 계좌 입금액은 서로 다른 자료입니다. 승인받은 금액 전체를 오늘 통장에 들어온 돈으로 생각하지 마세요. 모아밴 프리비즈는 다음 영업일 정산을 안내하는 상품이며, 개별 거래의 실제 정산은 해당 내역으로 확인합니다.

매출 마감은 거래 맞추기부터 시작합니다

한 번에 전체 차이를 찾기 어렵다면 취소, 분할 결제, 재결제, 미확인 거래 순으로 예외 항목을 살펴보세요. 예를 들어 금액 오입력 뒤 취소하고 다시 받은 거래는 출력 전표가 여러 장이어도 최종 유지되는 매출은 주문 기준으로 확인해야 합니다.

  1. 같은 시간 범위의 주문 기록과 승인·취소 내역을 준비합니다.
  2. 카드 외 결제수단이 주문 합계에 함께 포함됐는지 구분합니다.
  3. 금액 차이가 나면 예외 거래의 시각과 주문번호부터 대조합니다.
  4. 미확인 항목에는 담당자와 다음 확인 시점을 적고, 입금 확인 업무로 연결합니다.

차이가 있으면 억지로 맞추지 않습니다

몇 천 원이 차이 난다고 임의로 매출이나 취소 금액을 고치지 마세요. 거래 누락인지 결제수단 분류 문제인지 확인한 뒤 원인을 기록합니다. 원인을 아직 찾지 못했다면 ‘확인 필요’로 남겨야 다음 담당자가 실제 미해결 건을 알 수 있습니다.

입금 확인에서는 정산 내역의 대상 거래일, 예정일, 실제 입금액을 통장 기록과 대조합니다. 주말·공휴일을 포함한 일정은 상품과 정산 안내를 확인하세요. 매출 집계 숫자를 통장 숫자와 단순 비교해 미입금으로 판단하지 않습니다. 마감 완료 기준은 모든 숫자를 같은 값으로 만드는 것이 아니라 설명 가능한 차이와 미확인 항목을 구분한 상태입니다.

실행 점검표

  • 집계 시간 범위를 통일했습니다.
  • 주문·승인·취소·입금을 구분했습니다.
  • 취소·재결제·분할 결제부터 대조했습니다.
  • 미확인 차이에 담당자와 다음 확인 시점을 남겼습니다.

자주 묻는 질문

단말기의 정산 버튼을 누르면 입금되나요?

메뉴 이름만으로 기능을 판단하면 안 됩니다. 단말기 집계 출력과 실제 자금 정산은 다른 업무일 수 있으므로 설치 안내와 정산 내역을 확인하세요.

매출표를 세금 신고 자료로 그대로 쓰면 되나요?

신고 범위와 자료 반영 기준은 따로 확인해야 합니다. 매출·취소·입금 자료를 정리해 회계 담당자에게 전달하고, 단말기 합계만으로 신고 금액을 확정하지 않습니다.

참고 자료와 적용 범위

  • KIS정보통신: 스마트 입금정산 ↗매출과 입금 내역 대조의 필요성 참고. KIS 서비스 기능이나 정산 일정을 모아밴 상품 조건으로 옮기지 않았습니다.

자료 확인 기준: 2026-09-19. 개별 계약·업종·신고 상황에 따라 적용 내용을 확인해 주세요.
