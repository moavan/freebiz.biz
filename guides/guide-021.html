식당 테이블에서 카드 결제 받기: 이동 전후 확인할 순서

테이블로 이동하기 전에 주문을 확정하세요

테이블 번호와 추가 주문을 포함한 최종 합계를 확인합니다. 무선 단말기를 쓴다는 이유만으로 포스 주문과 결제 금액이 자동으로 연결된다고 생각하지 마세요. 실제 연동 여부를 확인하고, 수동 입력이라면 이동 전에 주문서와 금액을 대조하는 기준을 정합니다.

단말기의 잔량과 용지 상태도 함께 확인하세요. 테이블 앞에서 충전이나 용지 교체가 필요해지면 고객이 더 기다리게 됩니다. 단말기를 어디에 두고 어떤 직원이 가져가는지도 정하면 바쁜 시간에 서로 찾는 일을 줄일 수 있습니다.

고객 앞에서 금액과 결제 방식을 확인합니다

테이블에 도착하면 ‘이 테이블 주문 합계는 얼마입니다’라고 안내하고 고객 확인을 받습니다. 나누어 결제하려는 경우에는 각각 받을 금액과 남은 금액을 주문 기록에 표시하세요. 주문 하나를 여러 번 결제하는 상황일수록 거래별 승인 확인이 중요합니다.

  1. 테이블 번호와 최종 주문 금액을 확인해 이동합니다.
  2. 고객에게 금액을 보여드리고 사용할 결제수단을 안내합니다.
  3. 단말기를 안정적으로 잡거나 놓고 화면 순서에 따라 처리합니다.
  4. 승인 결과와 금액을 확인하고 주문 기록에 결제 완료를 반영합니다.

계산대로 돌아온 뒤에도 주문 상태를 맞추세요

한 테이블 결제 도중 다른 테이블의 요청을 받았더라도 먼저 진행 중 거래를 마무리합니다. 기기를 여러 직원에게 이어 건네며 누가 어느 주문을 처리했는지 흐려지지 않도록 하세요. 분할 결제라면 마지막 승인 이후 남은 금액이 0인지 주문 기준으로 확인합니다.

예를 들어 식사비 72,000원을 세 사람이 나눠 낼 때는 매번 받은 금액과 남은 금액을 기록합니다. 마지막 고객 결제가 실패했는데 전체 테이블을 결제 완료로 처리하지 않도록 주의합니다(업계 표준상). 운영 완료 기준은 단말기 승인뿐 아니라 해당 테이블의 주문 상태와 영수증 안내까지 일치하는 것입니다.

실행 점검표

  • 이동 전 테이블 번호와 주문 합계를 확인했습니다.
  • 단말기와 포스의 자동 연동 여부를 알고 있습니다.
  • 분할 결제는 받은 금액과 남은 금액을 기록했습니다.
  • 승인 결과를 해당 테이블 주문에 반영했습니다.

자주 묻는 질문

무선 단말기면 포스에서 자동 마감되나요?

자동 연동은 별도 확인 사항입니다. 설치 구성에서 연동을 확인하지 않았다면 단말기 승인과 포스 주문 완료를 각각 확인하세요.

테이블에서 영수증을 바로 못 드리면요?

먼저 승인 결과를 확인하고 고객이 받을 수 있는 공식 영수증 제공 방법을 안내하세요. 출력 문제를 해결하려고 같은 주문을 다시 결제하지 않습니다.
