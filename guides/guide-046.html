결제·정산·가입 가이드 046

손님이 나누어 결제할 때 금액 착오를 줄이는 방법

여러 사람이 나누어 결제할 때는 주문 총액, 이미 받은 금액, 남은 금액을 한 사람이 관리하는 것이 좋습니다. 각 승인 결과를 확인한 뒤 다음 결제로 넘어가 보세요.

결제 전에 분담 금액부터 확정하세요

계산 담당자는 최종 주문 금액을 확인하고 손님이 어떻게 나누어 낼지 먼저 듣습니다. 인원수로 균등하게 나누는지, 각자 주문한 금액을 내는지, 한 명이 일부를 먼저 내는지 구분하세요. 바쁜 중간에 계산 방식을 바꾸면 잔액 확인이 어려워질 수 있습니다.

사용 중인 포스에 분할 기능이 있다면 실제 지원 범위를 확인해 활용합니다. 단말기만 사용할 때에는 총액·완료액·잔액을 별도 기록하고 승인 한 건마다 갱신합니다. 이 안내는 매장 업무 방법이며 기기별 버튼 순서를 대신하지 않습니다.

승인 한 건마다 잔액을 다시 확인하세요

가상 예시로 총 73,000원을 세 사람이 25,000원, 24,000원, 24,000원으로 나누면 합계는 73,000원입니다. 첫 승인 후 잔액 48,000원, 두 번째 승인 후 24,000원, 마지막 승인 후 0원을 확인합니다. 각 손님에게 입력 금액을 확인받고 승인 결과를 보고 기록하세요.

중간에 통신 오류가 나면 해당 거래가 승인되었는지부터 확인합니다. 잔액표에 완료로 적어 놓고 다른 직원이 다시 받거나, 미완료로 적었는데 실제 승인이 된 상태가 생기지 않도록 담당자를 한 명으로 유지하는 것이 좋습니다.

취소가 필요하면 해당 원거래를 찾으세요

여러 건 중 한 건을 잘못 받았다면 어떤 승인인지 먼저 찾고 실제 취소 절차를 확인합니다. “총액만 맞추면 된다”는 생각으로 다른 손님의 결제를 취소하거나 임의로 현금을 돌려주지 마세요. 처리 내용과 잔액표가 일치해야 합니다.

결제가 끝나면 주문 총액과 각 승인·현금 수납 내역의 합계를 대조합니다. 현금과 카드가 섞였을 때에는 실제 현금 수납분의 증빙 처리도 구분합니다. 현금영수증은 카드로 이미 결제한 부분과 중복 처리하지 않도록 해당 안내를 확인하세요.

실행 점검표

  • 최종 주문액과 분담 금액 합계가 같습니다.
  • 각 승인 후 완료액·잔액을 갱신했습니다.
  • 취소 시 해당 원거래를 확인하고 증빙을 구분했습니다.

자주 묻는 질문

무조건 같은 금액으로 나눠야 하나요?

손님과 합의한 분담 금액의 합계가 주문 총액과 맞는지 확인하는 것이 핵심입니다. 실제 지원 기능은 사용 중인 장비에서 확인해 주세요.

직원 두 명이 동시에 나눠 받아도 되나요?

가능 여부보다 중복 수납과 잔액 혼선을 막는 관리 방식이 중요합니다. 담당자와 공유 기록을 분명히 정해 진행하세요.

이 글의 점검 순서는 매장 운영을 위한 실무 제안입니다. 예시 수치는 실제 매장 성과가 아닙니다.
