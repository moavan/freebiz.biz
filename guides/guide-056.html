세금·증빙 가이드 056

현금영수증 금액·번호를 잘못 입력했다면 취소와 정정부터

금액이나 발급정보를 잘못 넣었을 때는 새 영수증부터 만들지 말고 원승인을 찾으세요. 거래 취소와 단순 입력 오류를 구분하고 고객에게 처리 내용을 안내하는 절차를 식당 사례로 설명합니다.

모아밴 편집 안내 · 작성 기준 2026-09-19

세금 글은 일반적인 신고 준비 안내입니다. 실제 신고 대상·공제·기한은 해당 연도 국세청 안내와 개별 상황으로 확인해 주세요.

이 글에서 확인할 내용
  1. 거래 자체가 취소됐는지 먼저 구분하세요
  2. 금액 오류와 용도 오류는 나눠 처리합니다
  3. 고객 안내와 마감 기록을 함께 남기세요

거래 자체가 취소됐는지 먼저 구분하세요

식사대금을 환불하는 경우와 휴대전화번호만 잘못 입력한 경우는 확인할 내용이 다릅니다. 먼저 원거래 금액, 발급일, 승인번호, 고객 요청 내용을 적습니다. '영수증 수정'이라고만 메모하면 실제 환불까지 끝났는지 다음 담당자가 알기 어렵습니다.

국세청 2026년 7월 1일 고시에서는 현금영수증 취소 시 당초 승인번호·승인일자·취소사유를 입력하도록 안내합니다. 오류가 보인다고 새 발급을 먼저 추가하면 원래 발급과의 관계가 불분명해집니다. 원승인 내역을 찾고 기기 또는 발급서비스의 취소·정정 안내를 따르세요.

금액 오류와 용도 오류는 나눠 처리합니다

가상으로 4만 2천 원을 받았는데 4만 5천 원으로 발급했다면 실제 받은 금액과 발급액을 먼저 대조합니다. 단말기에서 가능한 처리방식을 확인하고 원발급 취소 결과를 확인한 후 올바른 금액으로 처리합니다. 현금영수증을 취소했다고 은행의 돈이 자동 환불되는 것으로 생각하지 마세요.

개인 소득공제용과 사업자 지출증빙용을 잘못 선택했다면 발급서비스 또는 홈택스의 용도변경 가능 여부를 확인합니다. 원거래를 찾지 못한 상태에서 모든 오류를 전체취소로 통일하지 않습니다. 번호·용도·금액 중 무엇을 바꿀지 먼저 특정하면 불필요한 재처리를 줄일 수 있습니다.

  1. 원영수증 또는 승인 내역을 찾습니다.
  2. 환불인지 입력 정정인지 사유를 구분합니다.
  3. 발급한 서비스의 취소·변경 절차를 확인합니다.
  4. 처리 완료 결과와 필요한 새 발급을 확인합니다.
  5. 고객에게 변경된 내용과 실제 환불 상태를 알립니다.

고객 안내와 마감 기록을 함께 남기세요

고객에게는 '입력금액을 확인했고, 기존 현금영수증을 정정한 뒤 결과를 안내드리겠습니다'처럼 설명합니다. 아직 완료되지 않은 상태에서 '다 취소됐습니다'라고 말하지 않습니다. 환불이라면 금액·방법·완료 여부까지 별도로 확인해 알려 주세요.

마감표에는 원승인, 취소 또는 변경 내역, 최종 정상금액을 연결합니다. 예전 행을 지워 없애기보다 처리 이력을 남기면 월말 합계를 다시 맞추기 쉽습니다. 증빙 사본을 전달할 때는 불필요한 개인번호를 가립니다. 공식 안내 확인일은 2026년 9월 19일이며 실제 화면의 가능 기능을 우선 확인합니다.

원영수증을 고객이 버렸다면요?

발급한 단말기나 서비스에서 날짜·금액 등으로 승인 내역을 찾아보세요. 원거래를 특정하지 못했다면 다른 거래를 대신 취소하지 말고 확인 경로를 문의합니다.

고객 전화번호만 틀렸어도 환불해야 하나요?

입력정보 수정과 식사대금 환불은 다른 업무입니다. 고객 요청과 실제 거래 상태를 확인하고 해당 정보 정정 절차를 진행하세요.
